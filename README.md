# Worth Services Website

My first internship website project, developed during my internship at **Softnovations**.

## About the Project

This website was created for **Worth Services Co., Ltd.** as part of my internship project at Softnovations.

The website presents the company's services, projects, company information, and contact details in a responsive and professional layout.

## Features

- Responsive design for desktop, tablet, and mobile
- Responsive navigation bar
- Mobile Control Center menu
- Animated navigation underline
- Hero section with responsive layout
- Introduction section
- About Us section
- Our Services section
- Our Projects section
- Contact Us section
- Responsive footer
- CSS animations and transitions

## Technologies Used

- HTML5
- Tailwind CSS
- CSS
- Git
- GitHub

## Pages

- Home
- About Us
- Our Services
- Our Projects
- Contact Us

## What I Learned

During this project, I learned how to:

- Build a complete website using HTML and Tailwind CSS
- Create responsive layouts for different screen sizes
- Structure website sections using clean HTML
- Create responsive navigation menus
- Add hover effects and CSS animations
- Work with images and SVG illustrations
- Test websites using Live Server
- Use Git and GitHub for version control
- Deploy a website using GitHub Pages
